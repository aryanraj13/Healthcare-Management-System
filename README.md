# Healthcare Management System

A modern healthcare web application designed to streamline patient management, appointment scheduling, and healthcare service interactions through an intuitive and responsive interface.

---

## 🚀 Features

- 👨‍⚕️ Patient registration and management
- 📅 Appointment scheduling system
- 🔐 Secure authentication and authorization
- 📱 Responsive user interface
- ⚡ Fast and optimized performance
- 🎨 Clean and modern design
- 📂 Structured frontend and backend architecture

---

## 🛠️ Tech Stack

### Frontend
- React.js / Next.js
- Tailwind CSS
- JavaScript / TypeScript

### Backend
- Node.js
- Express.js
- MongoDB
- REST APIs

---

## 📁 Project Structure

```bash
healthcare/

├── client/        # Frontend application

└── README.md
```

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/aryanraj13/healthcare.git
cd healthcare
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd server
npm install
```

---

## ▶️ Running the Project

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
npm start
```

---

## 🌐 Environment Variables

Create a `.env` file inside the `server` folder and add:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
